# Expo Integration

For Expo Android development builds launched through Valdroid.

- Build, install, start Metro, and launch the app.
- Reload JS, restart the app or Metro, and clear Metro cache.
- Reinstall without clearing app data, rebuild, or clean rebuild.
- View Metro/build logs and expandable JavaScript logs with source links.
- Inspect elements, highlight components, and jump to source files.
- Browse and search the component hierarchy and inspect props.
- Highlight React renders with React Scan.
- Reconnect the device stream without restarting the app.
- Rotate the display and adjust dark mode and text size.
- Save screenshots and record video with a timer and Stop button.

Development tools are injected without editing project files or installing app dependencies.
