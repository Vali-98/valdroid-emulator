# Contributing

Bug reports, documentation improvements, tests, and pull requests are welcome.
See [development notes](docs/DEVELOPMENT.md) for the project structure and tests.

By contributing original work, you agree to license that work under
AGPL-3.0-only, the project's existing license. You retain your copyright.
Do not contribute code you cannot license under those terms. Preserve the
licenses and copyright notices of third-party material; do not replace them
with Valdroid's license.

Please describe user-visible changes and include focused regression tests.
